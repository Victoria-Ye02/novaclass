# PDF Zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add accessible discrete zoom controls and keyboard shortcuts to the controlled lesson PDF viewer.

**Architecture:** Store the selected percentage inside `PdfLessonViewer`, derive the React-PDF scale from it, and reuse one clamped zoom function for toolbar and keyboard operations. Extend the existing guarded keydown listener without changing arrow navigation behavior.

**Tech Stack:** React 19, react-pdf 10, Vitest 4, Testing Library 16.

## Global Constraints

- Zoom levels are exactly 50%, 75%, 100%, 125%, 150%, 175%, and 200%.
- Percentage control resets to 100%.
- Command/Control with `+`, `-`, or `0` controls only PDF zoom.
- Inputs and the saved-page dialog retain their native keyboard behavior.
- Existing page, bookmark, and overlay interactions must remain unchanged.
